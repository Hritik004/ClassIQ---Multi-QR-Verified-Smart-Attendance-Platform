## 📖 About

ClassIQ is a modern attendance management system that ensures secure and reliable attendance tracking through **Dynamic Multi-QR verification**. It combines **Google OAuth Authentication**, **Email OTP verification**, attendance history, analytics, and an intuitive dashboard to provide a seamless experience for both faculty and students.

## ✨ Features

- 🔄 Dynamic Multi-QR Attendance
- 🔐 Google OAuth Authentication
- 📧 Email OTP Verification
- ⏱️ Time-Based QR Validation
- 👨‍🏫 Faculty Dashboard
- 👨‍🎓 Student Dashboard
- 📊 Attendance History & Analytics
- 🌗 Light & Dark Theme
- 🗄️ MySQL Database Integration
